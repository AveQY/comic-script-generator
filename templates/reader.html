📖 Reader API 文档

基础信息：所有 API 均以 / 开头，默认端口 8081。 如启用 COMIC_READER_API_KEY，所有请求需附加 ?api_key=<KEY> 或请求头 X-API-Key: <KEY>。

📚 项目（Projects）

GET/projects
列出所有项目（含漫画 / 轻小说），支持搜索与分页。
参数： search 项目名模糊匹配 · page 页码（默认 1）· page_size 每页数量（默认 20，最大 100）
curl 'http://localhost:8081/projects?page=1&page_size=20'
GET/projects/by-update
按"内容文件最后修改时间"降序列出项目（最新优先）。扫描 *.md（含 episodes/light_novel）和所有渲染图的 mtime 取最大值。
参数： limit 返回条数（默认 50，最大 200）· content_mode 过滤类型：comic 仅漫画 / light_novel 仅小说 / 省略为全部
curl 'http://localhost:8081/projects/by-update?limit=20&content_mode=light_novel'
GET/projects/{name}
获取单个项目详情：配置、统计、分集列表、图片画廊、轻小说章节。
路径参数：name 项目目录名（支持中文，需 URL 编码）
curl 'http://localhost:8081/projects/%E6%88%91%E7%9A%84AI%E8%80%81%E5%A6%88'
GET/project/{name}
/projects/{name} 的别名（兼容单数形式调用）。

📄 内容获取

GET/episode
获取漫画分集正文（Markdown 原文）。
参数： project 项目名（必填）· file 分集文件相对路径，如 episodes/ep001_xxx.md（必填）
curl 'http://localhost:8081/episode?project=Demo&file=episodes/ep001_start.md'
GET/doc
获取项目元数据文档（summary.md / characters.md / foreshadowing.md / style_guide.md 等）。
参数： project 项目名（必填）· file 文档文件名（必填）
curl 'http://localhost:8081/doc?project=Demo&file=characters.md'
GET/file
下载项目内任意文件（按 MIME 自动识别 Content-Type）。
参数： project 项目名（必填）· path 文件相对路径（必填）
curl -O 'http://localhost:8081/file?project=Demo&path=rendered/ep001/panel_03.png'
GET/thumb
生成图片缩略图（Pillow 实时压缩，JPEG 质量 78，缓存 1 天）。非图片文件原样返回。
参数： project 项目名（必填）· path 图片路径（必填）· width 目标宽度（默认 300，16–4096）· height 目标高度（默认 300，16–4096）· fit 缩放模式 cover（裁切填满）或 inside（完整保留）
curl 'http://localhost:8081/thumb?project=Demo&path=rendered/ep001/panel_03.png&width=400&height=400&fit=cover' > thumb.jpg

📖 轻小说

GET/light-novels
列出项目的轻小说章节（light_novel/ln*.md），返回标题、字数、访问 URL。
参数：project 项目名（必填）
curl 'http://localhost:8081/light-novels?project=%E6%88%91%E7%9A%84AI%E8%80%81%E5%A6%88'

🖥 页面路由

GET/
Reader 前端首页（番茄书架 SPA）。
GET/reader
Reader 前端（同 /，语义化路径）。
GET/health
健康检查，返回服务状态、项目根目录、端口、认证开关。无需 API Key。
curl 'http://localhost:8081/health'

🔐 认证

默认 不启用认证。设置环境变量 COMIC_READER_API_KEY=<KEY> 后， 除 /health 外的所有 API 都需要在请求中携带密钥：
# 方式 1：URL 参数 curl 'http://localhost:8081/projects?api_key=YOUR_KEY' # 方式 2：请求头 curl -H 'X-API-Key: YOUR_KEY' 'http://localhost:8081/projects'

⚙️ 环境变量

启动 Reader 服务器时可配置：
· COMIC_PROJECTS_ROOT — 项目根目录（默认 ~/comic-projects/projects）
· COMIC_READER_PORT — 监听端口（默认 8081）
· COMIC_READER_API_KEY — 可选 API 密钥（不设置则不启用认证）
COMIC_PROJECTS_ROOT=~/comic-projects/projects \ COMIC_READER_PORT=8081 \ uvicorn scripts.reader_server:app --host 0.0.0.0 --port 8081
错误码： 401 密钥无效 / 缺失 · 404 项目或文件不存在 · 500 服务器内部错误（详见响应 JSON 的 detail 字段）
路径安全： 所有接受文件路径的接口（/episode /doc /file /thumb）都会做路径穿越防护， 禁止访问项目根目录之外的文件。
