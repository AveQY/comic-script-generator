# 续写与修改工作流

## 续写前必须读取

续写时禁止只根据用户一句“继续写下一集”直接生成。必须读取：

1. `summary.md`：了解整体进度
2. `characters.md`：确认角色外貌、性格、说话方式
3. `foreshadowing.md`：确认未回收伏笔
4. `style_guide.md`：固定画风来源
5. 上一集最后 3 个 `Panel`：强制承接动作、台词、情绪或悬念

读取上一集末尾时，优先定位 `### Panel X` 标题，取最后 3 个 Panel；不要只按字符数粗暴截断。

## 新一集开头承接规则

新一集前 1-3 个 Panel 必须承接上一集最后 3 个 Panel 的动作、台词或悬念。若剧情需要跳切，必须在 `**转场**` 字段明确写明：时间跳切 / 场景转场 / 情绪转场 / 对比转场。

## 局部修改流程

### 用户指定 Panel 修改

当用户说“把第3集第7个 Panel 改一下”：

1. 定位到 `ep003_xxx.md` 中的 `### Panel 7`
2. 只修改该 Panel，不动其他 Panel
3. 保留必填字段：格子、画面、构图、气泡、旁白、拟声、转场、AI 提示词
4. 修改后检查：
   - 前后 Panel 是否连贯？
   - 气泡台词是否符合角色语气？
   - 转场是否说明清楚？
   - 是否引入新伏笔？
   - AI 提示词风格部分是否仍来自 `style_guide.md`？

### 用户指定情节修改

当用户说“让阿明在第5集发现真相”：

1. 检查 `foreshadowing.md`，看是否有相关伏笔
2. 如果伏笔已埋设，确认回收位置合理
3. 如果伏笔未埋设，在修改处新增伏笔记录
4. 更新 `summary.md` 中对应集数的“关键转折”
5. 检查本集结尾钩子和下集提示是否仍成立

## 伏笔管理

### 新增伏笔

在 `foreshadowing.md` 的“未回收”部分添加：

```markdown
- [ ] 阿明发现父亲旧照片中的神秘女子（第5集埋下）
```

### 回收伏笔

1. 从“未回收”移动到“已回收”
2. 标注回收位置：

```markdown
- [x] 阿明父亲的遗物（第2集埋下，第8集回收）
```

## 风格约束

同一项目中所有 Panel 必须读取同一个 `style_guide.md`。不得让 LLM 每个 Panel 自由拼风格词；只能变化人物动作、表情、构图、光线、场景物件和情绪氛围。
