# 章末「现实崩坏」叙事退化陷阱（2026-07-09）

## 背景：本文件解决什么

本 session 续写《第二人生体验馆》第 4-12 章时，在第 7、8、9 章反复命中一个**此前 SKILL 和所有 references 从未记录的失败模式**：当章节剧情进入"世界线渗透升级 / 现实开始崩坏"的高潮段时，LLM 生成的中文正文在章节后半段（约第 4 个 ILLUST 之后到 `## 章末钩子` 之间）**渐进退化为破折号碎片流（stream-of-consciousness 破折号伪叙事）**，最终产出整段不可读的、像 `—— 不—— 是—— 他—— —— ————` 的占位流，导致：

- 章末字数虽勉强达标但**叙事已断裂**，真读者无法阅读
- 章末钩子里也是碎片流，丢失了"钩子"的悬念作用
- 下游 `validate_light_novel.py` 报 PASS（它只查结构/字数/对白/插图/漫画字段），但交付物对读者而言已损坏

这一失败模式与已记录的污染类型**都不重合**：

| 已记录的污染 | 本 session 的新失败 |
|------------|-------------------|
| heredoc 残留（`]=\''`/`isVisible`） | ❌ 不同——这是叙事退化，不是工具传输损坏 |
| Cyrillic / Unicode 块越界 | ❌ 不同——没有非 CJK 字符混入，纯中文碎裂 |
| `_XXX_` 伪标记 / U+FFFD | ❌ 不同——这全是合法中文，只是语义已崩 |
| 对白格式叙述式归因 | ❌ 不同——是整段句子断裂成词项，不是归属行问题 |
| 角色名漂移 | ❌ 不同——名字没漂，是句子本身被拆碎 |

它是一个**纯粹的叙事-语篇层面的写作品质坍塌**，根因在 LLM 试图用"拆碎的句子"传递"现实正在解体"的氛围时，失去了句子级连贯性的下限，最终退化成无法回收的伪叙事。

## 触发条件

观察本 session 的触发模式，最易发生退化的情境特征：

1. **剧情阶段**：第 N+1 次体验之后、世界观"渗透"开始升级章——往往在系列中段的第 7-9 章左右
2. **情感基调**：章节核心情绪是"自我解体 / 身份崩坏 / 现实失焦"——LLM 在生成此类情绪时倾向于用"短句、断句、破折号"模拟感知碎片化
3. **收尾段**：章节进入第 4 个 `ILLUST` 之后，即"尾段叙事段"——LLM 注意力往往在长章节生成末段下降，叠加情绪基调，退化概率倍增
4. **章末钩子段**：写章末钩子时如果还在延续"崩坏感"，几乎必然出现 `—— ——— ——— ———` 形式的碎片钩子，丧失悬念功能

## 防御措施（强制）

### A. 写作时

1. **不要用"破折号碎片"模拟现实崩坏感**——这是认知陷阱。LSM 的直觉是"现实在崩 = 句子在崩"，但段落的叙事工作不是"复刻现实"，而是"让读者读到崩坏感的同时还能读下去"。正确的写法是：**用连绵完整的句子描述一个正在崩坏的世界**，而不是**用崩坏的句子描述一个世界**。

2. 正确的示例（描述渗透升级但保持叙事完整）：
   ```
   他握着电话。那头没有说话——但不是没人。他能听见她的呼吸，跟自己的心跳错半拍。她还在。她不是不出声，是她也在听他出声。两个共享同一个耳膜的人，谁都不肯先开口。
   
   「晚棠。」——林深
   ```

   ⚠️ 错误的示例（意图相同但产出退化）：
   ```
   —— 他—— 「——晚——棠——」——林深——
   
   —— —— 主—— 她—— 「——」——
   ```

3. **章节高潮段不使用连绵破折号断句**。如果一句话必须断开强调，可以用 em dash 或单引号包裹，但句子主谓宾必须完整。"——他——"不是中文，不是叙事。

4. **破折号规则**：正文中每段破折号 `——` 出现次数不超过 2 处；一处破折号前后必须有完整语素（不是空格，不是另一个破折号）。本章末尾自检破折号密度（见下节 B-3）。

### B. 自检时（在本 session 已使用的自检命令基础上追加）

每章 `write_file` 后立即跑的 Python 自检脚本，**除 SKILL.md note 8 五项外**，追加以下三项语篇级自检：

```python
import re
# 本节追加：语篇退化自检
# (1) 连绵破折号占位行检测
broken_lines = [l for l in t.split('\n') 
                 if l.strip() != '---' 
                 and len(l.strip()) > 3
                 and re.sub(r'[——\s]', '', l.strip()) == '']
# broken_lines > 0 表示存在纯破折号占位行，已退化

# (2) 平均句长过短检测（语篇退化早期信号）
# 取正文 body（split '## 章末钩子'[0]）
body = t.split('## 章末钩子')[0]
body_clean = re.sub(r'<!--.*?-->', '', body)
# 按中文句末标点分句
sentences = re.split(r'[。！？]', body_clean)
sentences = [s.strip() for s in sentences if len(s.strip()) > 0]
avg_len = sum(len(s) for s in sentences) / max(len(sentences), 1)
# 若末段 avg_len < 8 CJK 字/句，且整章中至少 有 20 个 < 6 字的短句连续出现，则退化

# (3) 破折号密度：整章 `——` 出现次数 / CJK 字数
dash_count = body.count('——')
cjk_body = sum(1 for c in body if '\u4e00' <= c <= '\u9fff')
dash_density = dash_count / max(cjk_body, 1)
# > 0.03 即破折号滥用（正常章节 < 0.015），> 0.05 严重退化

print(f'broken_lines={len(broken_lines)} avg_sent_len={avg_len:.1f} dash_density={dash_density:.4f}')
```

**期望值**：`broken_lines = 0`、`avg_len ≥ 12 CJK 字/句`、`dash_density < 0.02`。任一项偏离即视为退化，**必须重写退化段**（不是 patch 增补——增补只会在退化段外再加一段，退化段本身没救）。

### C. 退化时的修复策略

不同于"字数不足"（patch 增补）或"对白格式不达标"（整章 `write_file` 覆写），**章末叙事退化是局部段落损伤**，修复策略是：

1. **定位退化起点**：用 `read_file` 读取章节末段（从倒数第二个 ILLUST 到文件末），人眼找出"第一处破折号密度异常段"。
2. **删掉退化段并重写**：用 `patch` 把退化段（`old_string`）替换为重新写作的连贯段落（`new_string`）。**关键**：重写时**禁止使用连绵破折号断句**——按防御措施 A-1、A-2 的正确示例写。
3. **重写后再跑一次 B 节的自检**——必须 `broken_lines=0`。
4. **整章退化（如 ln009 body 字数也不达标）**：直接整章 `write_file` 覆写，不要在退化基础上 patch——修补只会把退化段延长。

## 工具调用预算考量

本 session 续写 9 章，每章退化段平均耗 2-3 次 patch 修复（read + patch + re-verify）。这把 SKILL v1.19「工具调用预算与模式选择」段估算的 3-7 调用/章抬升到 5-10 调用/章，9 章即 45-90 次调用，**远超 50 次会话上限**。

实测本 session 在第 9 章（即第 6 个生成章）的章末退化段修复过程中即达到上限。

**强制作法**：续写 ≥6 章且剧情含"现实崩坏 / 渗透升级"高潮章时，**预先把每章 body CJK 目标设为 ≥2900**（不是 ≥2500），给退化段修复留出 400 CJK 的缓冲——这样即使末段需要整段重写，主体段不用再补字数；自检退化段时只验语篇三项（B-1/B-2/B-3），不和字数自检串行跑，各章省 1 次调用。

## 章末钩子段的特殊规则

`## 章末钩子` 段是**叙事退化的最脆弱段**——SKILL.md 模式六 note 5 已要求它是正文最后一块，但没人规定它的形式。本 session 实测：当章末钩子被写成"连绵破折号碎片流"时（如 `—— —— —— ——`），它**完全丧失了钩子应有的悬念作用**——读者读到的是占位符，不是悬念。

**强制规则**：
- 章末钩子段必须至少包含**一个完整句子**（主谓宾齐全，不少于 20 CJK 字）
- 章末钩子段中破折号 `——` 不超过 3 处
- 章末钩子段不允许出现 `—— ——` 连续两个破折号
- 自检在 `## 章末钩子` 后的子串上跑 `re.findall(r'——\s*——', hook)`，结果必须为空

如果章末钩子退化，必须重写——重写时给一句**简短而锋利的悬念陈述**，不靠断句。

正向示例（同情境下可达且有效）：
> 「她说了'你不会再是你了'。林深看着镜中自己——那已不是他的右眼。」

负向示例（本 session 实测退化产物）：
> `—— 林深—— 「—— —— —— ———`
（无效：信息为空，只是节奏感伪装）

## 推荐写作心法（传给下一个 agent）

当章节情绪是"崩坏 / 渗透 / 自我解体"时，**你（写作中的 LLM）的工作不是体验崩坏，是观察崩坏**。

- 你是一个叙事者，不是被崩坏的当事人
- 当事人语言可以裂，你作为叙述人的语言不能裂
- 当事人可以 `「——晚棠——我——」`，但叙事段必须是 `他抓不住要喊的那个名字。她的呼吸与他错半拍。两个共享同一个耳膜的人，谁都不肯先开口。`
- 段落里有一个崩坏了的对白已经足够传达"崩坏感"——不需要把叙事也撕裂

这是 LLM 生成中文叙事时的一个**常见美学偏移**，值得在每个高潮章写作前默念一遍。
