# 小说大纲风格维度确认清单（2026-07-20《替考AI》实测）

## 背景与教训

本次为热点改编小说《替考AI》出大纲时，用户**连续 5 轮追加风格要求**：

1. 「悬疑更强一点，不需要没收AI，主要是斗智斗勇」
2. 「我希望还要有爽文色彩」
3. 「剧情可以和《台风夜便利店》《闪婚33万》结合吗」（多热点融合）
4. 「我希望结局不是完美的，而是有悬念的」
5. 「智斗元素丰富一点」

**根因**：首版大纲只确认了主线走向，没有确认风格维度，导致每轮都重写整份卷纲。**正确做法**：首次出大纲前，把下列五个维度**一次问全**，用户勾选后再动笔，可省掉 4 轮返工。

## 五维度确认模板（出大纲前直接发给用户）

```text
动笔前确认 5 个风格维度（可多选/组合）：

1. 类型强度（主次排序）：悬疑 / 治愈 / 热血 / 日常 / 情感
2. 爽文色彩（要不要、要哪些）：
   □ 打脸节奏（每次交锋赢得漂亮）
   □ 身份反转（主角是隐藏大佬，关键时刻亮身份）
   □ 金手指（超凡观察力/特殊人脉/技术搭档）
   □ 碾压快感（从被动到主动反杀）
   □ 不要爽文，写实向
3. 智斗密度：
   □ 单线对抗（你一招我一招）
   □ 多层博弈（你以为在第2层，其实在第5层，每2-3章一个反转）
   □ 身份迷宫（每个角色都不止一个身份）
4. 结局基调：
   □ 圆满收束（反派伏法、主角得偿所愿）
   □ 开放式悬念（看似胜利，实则暗流涌动，留白让读者思考）
5. 多线融合（限热点改编/多题材需求）：
   □ 单线到底
   □ 三线交织（主线骨架 + 副线场景 + 副线情感，靠人物关系和共用场景交织）
```

## 爽文元素库（维度 2 展开）

| 元素 | 用法 |
|---|---|
| 身份反转 | 主角表面普通（班主任），实为隐藏身份（前督导组副组长），卷三对峙时亮出 |
| 金手指 | 观察力/心理学/旧部人脉三选二，不要全给，留弱点 |
| 师徒联手 | 主角出谋略 + 配角出技术（黑客），互补型无敌组合 |
| 打脸节奏 | 每次交锋都赢，但赢得有代价或留新钩子，避免纯碾压变流水账 |
| 回归巅峰 | 结局回到开篇被贬之地（一中），风光收场——**开放式结局时不适用** |

## 智斗层级设计（维度 3 展开）

- **多层博弈表述公式**：「A 设局 → B 中计 → B 其实将计就计 → A 的将计就计也在 A 计算内」。每 2-3 章安排一次层级翻转，卷纲表格中给每章标注「智斗设计 + 反转」两列。
- **反向利用**：对手利用你的计划，你利用对手的利用——例：故意让 AI 窃听假情报；故意让对手黑进系统以获取其思维模式。
- **身份迷宫**：主角的"过去"也可以是伪造身份；内鬼抓到的只是替罪羊，真内鬼级别更高。
- **自我对抗（终极层）**：最终敌人是主角的数字化分身/思维模式副本——「它比你更了解你自己」。适合开放式结局。

## 多线融合技法（维度 5 展开）

将多个热点题材揉进同一部小说时：

1. **功能分工**：每个题材分一个角色——主线骨架（驱动剧情）、副线场景（关键爆发点）、副线情感（共鸣+调剂）。
2. **交织靠两样东西**：人物关系（副线B的角色其实是主线的卧底/记者/受害者）+ 共用场景（一个地标场景作为三线交汇点）。
3. **交汇场景递进出现**：同一个场景出现 3 次，每次功能升级——例：台风夜便利店第1次=发现线索，第2次=双方战场，第3次=最终对决。
4. **副线必须反哺主线**：副线角色掌握主线需要的关键证据/媒体资源/身份掩护，不能是装饰。

## 开放式结局模式（维度 4 展开）

| 技法 | 说明 |
|---|---|
| 表面圆满 + 细微异常 | 主角功成名就，但发现无法解释的细节（完美得不像人写的学生作文） |
| 匿名信息收尾 | 一条无法溯源的短信/邮件，暗示对手仍在（「你赢了这一局」） |
| 象征意象重现 | 开篇的意象在结尾重现但意味反转（台风再次来临） |
| 主角自我怀疑 | 最后一幕主角不确定自己是否也成了系统的一部分，留白不写死 |
| 禁止写死 | 反派不可被彻底消灭，只能"转入地下/进化成更隐蔽形态" |

## 迭代原则

- 大纲文档放在固定路径（如 `/tmp/<书名>_大纲.md`），用户每轮追加要求时**增量修订同一份文档**并在回复中只展示变更部分，不要每次全文重发。
- 用户说「就按照这个大纲完整的写完」之后才开始逐批生成章节——这句话是开工信号，此前只维护大纲。
