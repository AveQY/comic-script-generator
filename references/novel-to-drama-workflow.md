# 小说→短剧分镜脚本 工作流参考

## 概述

将小说章节（light_novel/ln*.md）转换为可拍摄的影视短剧分镜脚本。核心交付物为 storyboard/sbXXX_分镜.md（Seedance 2.0 时间轴格式或通用分镜表格式）。

## 工作流 5 阶段

### 阶段 1：事件提取 → novel_events.md

**输入**：单章小说正文（lnXXX_章名.md）
**输出**：novel_events/events_XXX.md

提取章节中的事件图谱，每事件一条：

```markdown
# 第X章 事件图谱

## 事件列表

| 序号 | 事件 | 冲突 | 情绪值 | 是否主线 | 关键对白/动作 |
|------|------|------|--------|----------|--------------|
| E01 | 主角在办公室收到匿名信 | 外部冲突 | 7/10 | 是 | 「这已经是第三封了。」 |
| E02 | 主角决定调查信件来源 | 内心冲突 | 5/10 | 是 | 主角打开电脑搜索 |
| E03 | 同事警告主角别多管闲事 | 人际关系冲突 | 8/10 | 是 | 「你最好别碰这件事。」 |
```

**字段说明**：
- 冲突类型：外部冲突 / 内心冲突 / 人际关系冲突 / 社会冲突
- 情绪值：1-10（10 为最激烈）
- 是否主线：是 / 否（支线标记，后续可决定是否保留或删减）
- 关键对白：逐字搬运原文台词（为后续△剧本准备）

**规则**：
- 每章至少提取 5-10 个事件
- 事件按时间顺序排列
- 关键对白必须原文逐字，不得缩写或改写
- 标注「情绪值」和「冲突类型」，供改编策略决策

### 阶段 2：改编策略 → adaptation_strategy.md

**输入**：novel_events/events_XXX.md + 全书设定
**输出**：adaptation_strategy.md

```markdown
# 改编策略

## 项目信息
- 源小说：《深夜电台主持人》
- 改编类型：小说 → 短剧（15秒/集，5集）
- 视觉风格：写实电影感，城市夜景，暖色调灯光
- 目标平台：竖屏 9:16

## 卖点锁定
- 一句话卖点：深夜电台，听见你的秘密——但主持人自己，也有不能说出口的秘密。
- 核心爽点：情感共鸣 + 反转 + 治愈
- 目标观众：18-35岁都市上班族，情感治愈需求

## 素材清单（改编范围）
| 章节 | 包含事件 | 保留/删减/合并 | 决策理由 |
|------|---------|----------------|----------|
| ln001 | E01-E02 | 保留 | 开场建立人设，必需 |
| ln001 | E03-E04 | 保留 | 冲突铺垫，必需 |
| ln001 | E05-E06 | 合并为1场 | 节奏紧凑，删减次要对话 |
| ln002 | E01-E03 | 保留 | 情节推进，必需 |
| ln002 | E04-E05 | 删减 | 支线，不影响主线 |

## 爆点分布
- 第1集：黄金三秒 + 第一个冲突
- 第2集：情绪拉扯 + 小反转
- 第3集：阶段打脸/反转
- 第4集：情绪高潮
- 第5集：真相揭露 + 结尾留钩

## 删减原则
1. 删减支线事件（不影响主线理解的背景/角色）
2. 合并同类情绪事件（连续两个低情绪值事件可合并）
3. 保留冲突事件（不删减情绪值 ≥7 的事件）
4. 保留关键对白（不删减推动剧情或揭示角色内心的台词）

## 投流爆点约束
- 第1集开头3秒必须有强冲突/强悬念/强反差（黄金三秒）
- 必须在前3秒内展现核心冲突
- 每集结尾必须有钩子
```

**△ 剧本格式规则**：
1. 每个镜头以 `△ ` 开头（三角形+空格），后接镜头描述
2. 第一行格式：`X-X 昼/夜 内/外 场景名`
3. 道具和出场人物在场景首行之后列出
4. 对白格式：`角色名（情绪/状态）：对白内容`
5. 特殊标注：`内心独白`、`画外音`、`【字幕】`、`【空镜】`、`【闪回】`/`【闪回结束】`
6. 运镜必须具体：推/拉/摇/移/跟/环绕/升降 + 景别（远景/全景/中景/近景/特写/大特写）
7. 每集结尾必须有钩子（一个未解决的动作 / 一句暗示 / 一个悬念画面）

## 分镜核心铁律

以 Toonflow 原文为准，以下规则必须严格遵守：

1. **台词零删改**：原文台词逐字搬运，不得缩写、改写、合并。即使原台词较长，也必须完整保留，通过拆镜换景别来适配时长。

2. **长台词拆镜**：单句台词 >20 字（约 5 秒），必须拆分为多个镜头，每个镜头使用不同景别（如：中景→近景→特写），避免单一镜头过长。

3. **时长计算**：4字/秒，单片段/单镜头 ≤15 秒。15 秒标准短剧集，建议 5-8 个镜头。

4. **出场人物不消失**：一旦角色在某场景出场，直到该场景结束前不得无故消失。角色退场必须有明确动作（离开、转身、倒下等）。

5. **外观不进提示词**：角色提示词只写**动作/表情/状态**，不写外观描述（外观已在资产清单 C01-C99 中定义）。画面描述中只写：`主持人推门进入`，不写`主持人（30岁，黑框眼镜，深蓝衬衫）推门进入`。

6. **声音设计**：只写**环境音 + 音效**，禁止写 BGM/配乐/背景音乐。允许的：`脚步声`、`门吱呀声`、`风声`、`心跳声`、`电话铃声`、`城市环境音`、`悬疑氛围音效`。

7. **片段间过渡**：三个过渡方式——动作桥梁（上一镜关门，下一镜开门）、情绪接力（上一镜愤怒，下一镜爆发）、空间视线链接（上一镜看向窗外，下一镜窗外景色）。

8. **尾帧衔接**：每集末尾附「尾帧描述」，下集首镜必须承接尾帧的画面/动作/情绪/光线。

9. **字段隔离**：分镜文件（storyboard/sbXXX.md）和 △ 剧本文件（drama_scripts/epXXX.md）中禁止出现以下漫画字段：`**格子**`、`**构图**`、`**转场**`、`### Panel`、`## Page`、`---`（分隔符除外）、`气泡`、`旁白`、`拟声`。

10. **写入规则**：中文正文写入禁止 heredoc，用 `write_file` 或 Python 脚本写入。写入后验证结构完整性。
